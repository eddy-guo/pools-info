## Design and images

The user approved the older mixed teal/pink export temporarily. The versioned
`design/poolsinfo.html` removes the rendered Uniswap wordmark and embedded SVG.
`DESIGN-DELTA.md` records the source filename, mtime, hash and changes.

Image metadata is a creator claim attached to a verified launch. Browsers use
only a local pool-ID endpoint. Fetches require HTTPS, exact reviewed hosts,
public DNS with IP pinning, no redirects, bounded time/bytes/pixels/concurrency,
and raster re-encoding into WebP. IPFS uses Pinata's public gateway: it sees the
server IP and CID, not visitor cookies or wallets. No new API key is required.
See `docs/TOKEN-IMAGES.md` for policy, privacy and best-effort availability.
The deployed route served a real BANKZ image as HTTP 200, `image/webp`, 1,296
bytes. A sample of 100 recent catalog entries contained five image claims;
this is not a coverage estimate for the full launch population.
